# AK-1 Camera Update

این نسخه از AK-1 شامل دوربین واقعی گوشی است.

- تصویر زنده با پکیج Flutter `camera`
- درخواست دسترسی دوربین و میکروفون در Android
- تعویض بین دوربین‌های موجود
- کنترل فعال/غیرفعال کردن صدای دوربین
- مدیریت چرخه حیات برنامه برای آزاد/راه‌اندازی دوباره دوربین
- آماده برای اتصال بعدی به ماژول بینایی هوش مصنوعی

مسیر Builder همچنان در `.github/workflows/build-apk.yml` قرار دارد.

# ESP32-CAM firmware

این پوشه برای AI-Thinker ESP32-CAM است.

## نکته پین‌ها

ESP32-CAM پین‌های آزاد محدودی دارد و بعضی GPIOها با بوت، PSRAM یا دوربین اشتراک دارند. بنابراین پین‌های موتور/DFPlayer را بدون تطبیق با برد دقیق خودتان قطعی نکنید.

برای نسخه فعلی، این فایل یک اسکلت ارتباطی امن و قابل توسعه است؛ قبل از اتصال واقعی موتور، تغذیه و صوت، pin map و ولتاژهای بردهای واقعی را بررسی کنید.

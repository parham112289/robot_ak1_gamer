# AK-1 Laptop Agent

این Agent برای اتصال واقعی اپ Flutter به لپ‌تاپ در شبکه محلی است.

## اجرا

روی لپ‌تاپ Python 3 نصب باشد و اجرا کن:

```bash
python agent.py
```

سپس در اپ AK-1 آدرس لپ‌تاپ را مثل `192.168.1.100:8765` وارد کن.

این نسخه فقط اتصال، سلامت Agent، وضعیت پایه و دریافت درخواست‌های allowlist شده را فراهم می‌کند. اجرای نصب/حذف برنامه، اجرای shell دلخواه، دسترسی به رمزها و کنترل مخفیانه عمداً فعال نشده‌اند.

برای نمایش زنده صفحه لپ‌تاپ، مرحله بعدی باید یک مسیر WebRTC با pairing امن اضافه شود؛ UI آن در اپ آماده است ولی این Agent هنوز stream واقعی ارسال نمی‌کند.

# اپ AK-1

این پوشه یک پروژه Flutter است.

برای اجرای محلی:

```bash
flutter pub get
flutter run
```

در صورت نبودن فایل‌های Android، دستور زیر را یک بار اجرا کنید:

```bash
flutter create --platforms=android .
```

درصد باتری در اپ وجود ندارد؛ فقط ولتاژ در صورت دریافت از backend نمایش داده می‌شود.
